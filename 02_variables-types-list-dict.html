Les types int, float, str, bool

4 types de base

Quand on déclare une variable, python “comprend” de quel type il s’agit.

quantity = 3            # int   : entier
price = 12.5            # float : nombre à virgule
product = "Café"        # str   : chaîne de caractères
in_stock = True         # bool  : vrai / faux

L’instruction type() permet de vérifier le type d’une variable :

print(type(quantity), type(price), type(product), type(in_stock))
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>

Opérateurs de calcul

On peut calculer avec : +, -, *, /, **.

number = 400
rate = 3/100
years = 10
print(number * rate)
print(number * (1 + rate)**years)   # ** : puissance
12.0
537.5665517376489

Focus sur le type str

👉 C’est l’objet de l’exercice 1.

Déclaration d’une string

On peut utiliser les guillemets simples ou doubles.

print('Hello world !')        # Guillemets simples
print("J'étudie l'économie")  # Guillemets doubles, pratiques pour les apostrophes
Hello world !
J'étudie l'économie

On peut utiliser les triples guillemets pour les chaînes de caractères sur plusieurs lignes.

long_string = """
This string is on
multiple
lines
"""
print(long_string)

This string is on
multiple
lines

Extraction d’une substring

  • Un str est une suite de caractères, indexée à partir de 0.
  • [a:b] permet d’extraire les caractères
    • à partir de la position a
    • jusqu’à la position b exclue (c’est à dire juste avant)

⚠️ La première lettre est à la position 0.

country = "France métropolitaine"
print(country[2:5])  # de la 2e à la 4e lettre
print(country[:5])  # jusqu'à la 4e lettre
print(country[5:])  # à partir de la 5e lettre
anc
Franc
e métropolitaine

Opérateurs sur les chaînes de caractères

On dispose des opérateurs + et *, mais ce ne sont pas des opérations mathématiques.

country = "France"
print(country + " métropolitaine")   # concatenation
print(country * 3)                   # repetition
France métropolitaine
FranceFranceFrance

Les f-strings : interpolation

On peut insérer une variable.

Préfixe f avant les guillemets, expressions entre { }.

gdp = 2917.8
pop = 68.4
print(f"PIB : {gdp} Mds€, population : {pop} M")
PIB : 2917.8 Mds€, population : 68.4 M

Les f-strings : formattage

💡 Contenu non exigible à l’examen, utile pour aller plus loin

On peut formater les nombres, comme dans un tableur.

Exemples de formats :

  • .2f : 2 décimales
  • .1% : pourcentage ave 1 décimale
  • , : séparateur de milliers anglosaxon
  • .2e : notation scientifique

En pratique :

total = 1234.5678
print(f"Two decimals: {total:.2f}")
print(f"Comma-separated: {total:,.2f}")
print(f"As percent: {0.875:.1%}")
print(f"Scientific:  {total:.2e}")
Two decimals: 1234.57
Comma-separated: 1,234.57
As percent: 87.5%
Scientific:  1.23e+03

Les listes

Définition

Une liste est une collection d’éléments ordonnés et modifiables.

On la déclare entre crochets (🇺🇸 square brackets) [].

x = [10, 'foo', False]
type(x)
list

On obtient le nombre d’éléments avec len() :

len(x)
3

Accéder à un élément

Chaque élément de la liste est numéroté par son indice (ou index).

⚠️ Les indices commencent à 0 ! :

x = ["John", "Paul", "Georges"]
print(x[0])
print(x[2])
John
Georges

Ajouter un élément

On utilise la méthode .append() :

x = ["John", "Paul", "Georges"]
x.append("Ringo")
x
['John', 'Paul', 'Georges', 'Ringo']

Supprimer un élément

On utilise la méthode .remove() ou del :

print(x)
x.remove("Ringo")  # Remove a specific value
print(x)

del x[1]  # Remove a specific index
print(x)
['John', 'Paul', 'Georges', 'Ringo']
['John', 'Paul', 'Georges']
['John', 'Georges']

Mettre à jour un élément

On modifie directement l’élément en lui réaffectant la nouvelle valeur.

x= [1, 145, 3, 4, 5]
x[1] = 2
x
[1, 2, 3, 4, 5]

Extraire une sous-liste (slicing)

On utilise un slicer de type [debut:fin] avec les indices de la liste.

⚠️ Attention : cela renvoie les termes de l’indice debut à l’indice fin-1.

⚠️ …et on n’oublie pas que le premier élément de la liste a pour indice 0 !

x = ["a", "b", "c", "d", "e", "f", "g"]
x[3:6]
['d', 'e', 'f']

Slicing avancé

La syntaxe générale d’un slicer est [debut:fin:pas], et les nombres peuvent être négatifs.

x = ["a", "b", "c", "d", "e", "f", "g"]

print(x[:6])  # tous les éléments jusqu'au 5e (=6-1)
print(x[3:])  # tous les éléments à partir du 4e (=d'indice 3)
print(x[1:6:2])  # de l'indice 1 jusqu'à l'indice 5, par pas de 2
print(x[-1])  # le dernier élément
print(x[-3:])  # les 3 derniers éléments
print(x[::-1])  # tous les éléments, en sens inverse
['a', 'b', 'c', 'd', 'e', 'f']
['d', 'e', 'f', 'g']
['b', 'd', 'f']
g
['e', 'f', 'g']
['g', 'f', 'e', 'd', 'c', 'b', 'a']
  • si on omet debut, on commence au début de la liste
  • si on omet fin, on va jusqu
  • on peut utiliser des nombres négatifs pour p

Les dictionnaires

Définition

Dans un dictionnaire, chaque valeur est associée à une clé. C’est une collection non ordonnée d’éléments.

On le note entre accolades (🇺🇸 curly braces) {}, avec des paires clé: valeur séparées par des virgules.

d = {'name': 'Harry', 'age': 33}
type(d)
dict

Accéder à un élément

Dans une liste, on utilise les indices pour accéder aux éléments.

Dans un dictionnaire, on utilise les clés.

Chaque clé doit donc être unique.

d = {'name': 'Harry', 'age': 33}
d['age']
33

Ajouter un élément

Pour ajouter un élément, on l’affecte directement à sa clé.

d = {'name': 'Harry', 'age': 33}
d['size'] = 1.75
d
{'name': 'Harry', 'age': 33, 'size': 1.75}

Supprimer un élément

La fonction del supprimer une clé et sa valeur associée.

d = {'name': 'Harry', 'age': 33, 'size': 1.75}
del(d['size'])
d
{'name': 'Harry', 'age': 33}

La méthode pop supprime une clé et renvoie sa valeur.

d = {'name': 'Harry', 'age': 33, 'size': 1.75}
val = d.pop('size')
print(d)
print(val)
{'name': 'Harry', 'age': 33}
1.75

Mettre à jour un élément

On peut mettre à jour un élément en lui affectant une nouvelle valeur.

d = {'name': 'Harry', 'age': 33, 'size': 1.75}
d['age'] = 34
d
{'name': 'Harry', 'age': 34, 'size': 1.75}
