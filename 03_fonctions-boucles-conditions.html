Séance 3 — Fonctions, strutures conditionnelles, boucles

Introduction à Python · L3 Économie-Gestion

Objectifs

Connaissances à maîtriser :

  • Définir et appeler une fonction avec des arguments et un return.
  • Ecrire un script conditionnel avec if / elif / else.
  • Répéter un traitement avec for (notion de boucle).
  • Boucler sur une liste et sur un dictionnaire.

Les fonctions en python

Un exemple et du vocabulaire

def half(number):
    return number*0.5
  • La fonction s’appelle half
  • Elle prend un paramètre : number
  • Elle retourne un float
result = half(10)
result
5.0
  • Ici on appelle la fonction avec l’argument 10
  • On stocke le résultat dans la variable result

Ce qui se passe dans une fonction reste dans la fonction

💡 A l’intérieur de la fonction, le code est indenté (tabulation).

def add_tax(price):
    total = price * 1.2
    return total

result = add_tax(100)
result
120.0
print(total)
---------------------------------------------------------------------------
NameError                                 Traceback (most recent call last)
Cell In[4], line 1
----> 1 print(total)

NameError: name 'total' is not defined

👉 total n’existe qu’à l’intérieur de la fonction (portée locale).

Plusieurs arguments ?

On peut passer plusieurs arguments à une fonction, et les rendre facultatifs.

def add_tax(price, rate=0.2):
    return price * (1 + rate)
add_tax(100, rate=0.05) # tax rate is 5/100
105.0
add_tax(100)  # tax rate not provided, default value is used
120.0

Plusieurs résultats ?

Si on veut renvoyer plusieurs valeurs, on peut renvoyer une liste.

… ou un dictionnaire

… ou simplement deux valeurs, séparées par une virgule.

def format_name(name):
    return name.upper(), name.lower()

format_name("jOhn LEnNon")
('JOHN LENNON', 'john lennon')

💡 En réalité return a, b renvoie un tuple (a, b). Le tuble est un type de données qui ressemble aux listes.

On peut récupérer chacun des éléments du tuple en utilisant l’unpacking :

upper_name, lower_name = format_name("jOhn LEnNon")
print(upper_name)
print(lower_name)
JOHN LENNON
john lennon

Structures conditionnelles

Tout est dit en un exemple

inflation = 3.2
if inflation > 2:
    print("au-dessus de la cible")
elif inflation > 0:
    print("en dessous de la cible")
else:
    print("déflation")
au-dessus de la cible
  • Comme pour les fonctions, les : et l’indentation délimitent le bloc.
  • elif et else sont optionnels.
  • La condition est un booléen : x > 2, name == "France", x in liste, …

Boucles for

Parcourir une liste

countries = ["France", "Allemagne", "Italie"]
for c in countries:
    print(c.upper())
FRANCE
ALLEMAGNE
ITALIE

À chaque itération, le curseur c prend la valeur suivante de la liste.

On peut aussi boucler en récupérant à la fois la valeur et l’index :

countries = ["France", "Allemagne", "Italie"]
for index, c in enumerate(countries):
    print(index, " - ", c.upper())
0  -  FRANCE
1  -  ALLEMAGNE
2  -  ITALIE

Parcourir des valeurs numériques

On utilise la clause range(start, stop, step). Comme pour les listes, stop n’est pas inclus, et step est optionnel.

for year in range(2020, 2023):  # 2023 not included
    print(year)
2020
2021
2022
for n in range(1, 5, 2):
    print(n)
1
3

Très souvent, on utilise range(n) pour répéter un traitement n fois :

for n in range(5):
    print('Hello !')
Hello !
Hello !
Hello !
Hello !
Hello !

Parcourir un dictionnaire

Rappel : Un dictionnaire contient des paires clé–valeur.

scores = {"Alice": 15, "Bob": 12, "Charlie": 18}

Avec une boucle for, on peut parcourir ses clés, ses valeurs ou les deux simultanément.

for name in scores.keys():
    print(name)

for score in scores.values():
    print(score)

for name, score in scores.items():
    print(f"{name}: {score}")
Alice
Bob
Charlie
15
12
18
Alice: 15
Bob: 12
Charlie: 18

Utiliser une boucle pour construire une liste

capital = 1000
history = []
for year in range(5):
    capital = capital * 1.03
    history.append(round(capital, 2))
history
[1030.0, 1060.9, 1092.73, 1125.51, 1159.27]

🤯 Version compacte (list comprehension), cf. exercice 4 :

history = [round(1000 * (1.03) ** year, 2) for year in range(5)]
history
[1000.0, 1030.0, 1060.9, 1092.73, 1125.51]

Boucles while

Un exemple

capital, year = 1000, 0
while capital < 2000:
    capital = capital * 1.05
    year += 1
print(f"Capital doublé après {year} ans")
Capital doublé après 15 ans


👉 while répète le contenu de la boucle tant que la condition est vraie. Utile quand on ne connaît pas le nombre de tours à l’avance. Attention aux boucles infinies : la condition doit finir par devenir fausse.
