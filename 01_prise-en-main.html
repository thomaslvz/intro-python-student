Introduction à Python · L3 Économie-Gestion

Présentation du cours

Pourquoi Python en économie-gestion ?

  • Le langage le plus utilisé en analyse de données (banques, instituts statistiques, cabinets de conseil, INSEE…).
  • Gratuit, lisible, énorme communauté → documentation et exemples partout.
  • Un écosystème de bibliothèques : numpy (calcul), pandas (tableaux de données), matplotlib (graphiques), statsmodels (économétrie), scipy (optimisation).

Note

Ce cours va de la découverte de la programmation jusqu’à l’utilisation de python pour l’analyse de données… en 21h. On n’apprend pas tout Python, l’objectif est de devenir autonome pour savoir apprendre, c’est à dire savoir aller chercher l’information.

Objectifs

A l’issue du cours, l’étudiant.e doit être capable de :

  • utiliser un environnement de développement (IDE) Python et organiser ses fichiers (données, notebooks, code python) ;
  • écrire et exécuter des programmes Python simples, et notamment :
    • maîtriser les concepts de variables, types, structures de données, conditions, boucles et fonctions ;
    • manipuler vecteurs et des matrices avec NumPy ;
    • importer, explorer, nettoyer et transformer des données avec pandas ;
    • calculer et interpréter des statistiques descriptives ;
    • produire des visualisations simples avec matplotlib ;
    • utiliser un solveur simple avec scipy
    • estimer et interpréter une régression linéaire simple avec statsmodels ;
  • utiliser la documentation officielle pour débuguer ses programmes ;
  • réaliser une analyse élémentaire de données économiques en mobilisant l’ensemble de ces outils.

JupyerLab

JupyerLab c’est quoi ?

C’est un Environnement de développement (IDE, en anglais).

Il se lance depuis un Terminal, et s’ouvre dans votre navigateur web.

Depuis JupyerLab, on peut :

  • 📁 parcourir ses fichiers (créer, supprimer, déplacer, etc.)
  • écrire du code dans des scripts python
  • exécuter des sripts python, à l’aide d’un Terminal
  • 📝 prendre des notes, au format Markdown
  • ouvrir des Notebooks python dans lesquels on mélange des notes et du code

👨‍🏫 Démo !

Lancer JupyterLab depuis son dossier de travail

👉 Il faut savoir où est votre dossier de travail

  • ordinateur UGA : Ce PC > /votre nom d'utilisateur/ > intro-python
  • ordinateur perso : /votre dossier utilisateur/ > intro-python

L’interface Jupyterlab

  • À gauche : l’explorateur de fichiers. Vous naviguez dans vos dossiers.
  • Au centre : les onglets (notebooks, fichiers texte, terminaux).
  • Launcher (bouton +) : créer un notebook, un fichier texte, un terminal, une console Python.

3 types de fichiers à connaître

Le texte au format markdown

Fichier de type *.md.

  • on peut l’éditer en l’ouvrant
  • ou le visualiser (Open with... > Markdown Preview)

Le script python

Fichier de type *.py

On exécute un script depuis un Terminal avec

python <nom du script>

Le notebook python

Fichier de type *.ipynb

Il est organisé en cellules :

  • cellules de code (python)
  • cellule de texte (markdown)

🤔 Exécuter une cellule dans un notebook


Cellule de code

prix = 12.5
quantite = 3
prix * quantite

Exécuter : Shift + Entrée. Le résultat de la dernière ligne s’affiche.

Cellule de texte (Markdown)

## Titre de section
Du texte, une *emphase*, du **gras**,
une liste :
- point 1
- point 2

Exécuter : Shift + Entrée. Le texte s’affiche tel quel.

🤔 Raccourcis indispensables dans un notebook


Action Raccourci
Naviguer d’une cellule à l’autre Flèches ↑ et ↓
Exécuter la cellule et passer à la suivante Shift + Entrée
Passer la cellule en Markdown / en code M / Y
Ajouter une cellule au-dessus (above) / en dessous (below) A / B
Supprimer une cellule D, D

Important : pour réaliser ces actions, il faut d’abord appuyer sur la touche Échap pour sortir de l’édition de la cellule.

Pour voir tous les raccourcis clavier : Help > Show keyboard shortcuts...
