# Parcours d'exercices TD3

_Ce parcours d'exercices s'appuie sur la plateforme Coding Practice pour travailler les notions de la séance n°3._

**Thématiques travaillées :** fonctions, conditions, boucles.

**Utilisation recommandée :**

👉 Parcours "je maîtrise les bases" :

- faire tous les exercices "échauffement"
- piocher 4 exercices dans la partie "intermédiaire"

👉 Parcours "je révise pour un examen" :

- piocher au hasard des exercices de révision dans la partie "intermédiaire"

👉 Parcours "je veux aller plus loin" :

- faire les exercices bonus

NB: les étoiles représentent le niveau de difficulté.

**Exercices :**

1. Echauffement
   - Fonctions ⭐ — [Additionner deux nombres](https://codingpractice.online/problems/sum-of-two-numbers)
   - Conditions ⭐ — [Catégorie d'age](https://codingpractice.online/problems/age-category)
   - Boucles for ⭐ — [Somme de 1 à N](https://codingpractice.online/problems/numbers-up-to-n)

2. Niveau intermédiaire
   - Fonctions :
     - ⭐⭐ [Construire un nom complet](https://codingpractice.online/problems/build-full-name)
   - Conditions:
     - ⭐⭐ [Comparer deux str](https://codingpractice.online/problems/compare-string-length)
     - ⭐⭐ [Classer une note](https://codingpractice.online/problems/grade-from-score)
     - ⭐⭐⭐ [Additionner au dessus d'un seuil](https://codingpractice.online/problems/sum-field-above-threshold)
   - Boucles:
     - ⭐⭐ [Table de multiplication](https://codingpractice.online/problems/multiplication-table)
     - ⭐⭐ [Compter les `true`](https://codingpractice.online/problems/count-trues)
     - ⭐⭐ [Lettres vs. nombres](https://codingpractice.online/problems/count-letters-vs-digits)
     - ⭐⭐⭐ [Compter les voyelles](https://codingpractice.online/problems/count-vowels-loop)
     - ⭐⭐⭐ [Compter les majuscules](https://codingpractice.online/problems/count-uppercase)
     - ⭐⭐⭐ [Trouver le maximum](https://codingpractice.online/problems/find-max-loop)
3. Bonus
   - ⭐⭐⭐⭐ [Applatir une liste](https://codingpractice.online/problems/flatten-list) (à faire uniquement avec des boucles, **sans** utiliser `numpy`)
   - ⭐⭐⭐⭐ [Vérifier un palindrome](https://codingpractice.online/problems/valid-palindrome)
   - ⭐⭐⭐⭐ [Préfixe commun le plus long](https://codingpractice.online/problems/longest-common-prefix)
